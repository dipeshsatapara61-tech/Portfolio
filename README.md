# Dipesh Satapara - Personal Portfolio Website

A modern, minimalist, and visually impressive personal portfolio website tailored for **Dipesh Satapara**, an aspiring Business Analyst & Data Analyst.

![Portfolio Preview](/public/images/olist-dashboard.svg)

## 🌐 Live Preview & Tech Stack

- **Framework**: React 18 + Vite
- **Styling**: Modern CSS3 (Custom Design System, CSS Variables, Glassmorphism)
- **Icons**: Lucide Icons
- **Color Theme**: Deep Navy (`#0B1120`), Dark Slate Card (`#151F32`), Electric Sky Blue (`#38BDF8`), Soft Indigo (`#818CF8`)
- **Typography**: Plus Jakarta Sans, Inter, JetBrains Mono

## 🛠️ Running Locally

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start the development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

3. **Build for production**:
   ```bash
   npm run build
   ```

4. **Preview production build**:
   ```bash
   npm run preview
   ```
